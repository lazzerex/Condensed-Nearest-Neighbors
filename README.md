# Demo Condensed Nearest Neighbor (CNN)

Demo cho bài toán rút gọn tập huấn luyện trên bộ dữ liệu Shuttle bằng Condensed Nearest Neighbor.

## Nội dung chính

- Dataset: Shuttle
- Khảo sát nhanh dữ liệu
- Huấn luyện kNN baseline
- Cài đặt Condensed Nearest Neighbor (CNN)
- Đánh giá trước/sau khi rút gọn
- Trực quan hóa kết quả
- So sánh thời gian huấn luyện và dự đoán
- Lưu mô hình

## File chính

- `cnn.ipynb`: notebook demo Condensed Nearest Neighbor
- `Data/train_shuttle.csv`: dữ liệu train
- `Data/test_shuttle.csv`: dữ liệu test
- `Output/CNN_Shuttle.mdl`: mô hình đã lưu
- `Output/cnn_dataset_summary.csv`: bảng thông tin dữ liệu
- `Output/cnn_label_distribution.csv`: phân bố nhãn
- `Output/cnn_label_distribution.png`: biểu đồ phân bố nhãn
- `Output/cnn_numeric_corr.png`: ma trận tương quan các đặc trưng
- `Output/cnn_comparison_summary.csv`: bảng tổng hợp so sánh kết quả
